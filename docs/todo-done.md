- [x] **Settings reported the Claude account "logged out" after an idle night** (2026-07-28, `1e13431`). Long-running symptom, finally reproduced from the user's side: Settings → Agents → Claude read *Disconnected — "Claude login has expired. Run claude /login again."*, yet opening a session and sending a message worked, and the panel flipped to Connected right after the reply. - [x] **Chat: shimmering "Thinking…" text hitches once per loop** (2026-07-23, `973c926`). Reported as "one pass animates smoothly, then the second skips back a few pixels". `background-position` percentages resolve against *(element width − background width)*, not element width — with `bg-[length:250%_100%]` that factor is −1.5W, so the `200% → -200%` keyframe pair slid the gradient 6W per cycle while the tile repeats every 2.5W. 6 ÷ 2.5 = 2.4 tiles, so every cycle ended 0.4 of a tile out of phase and snapped. Fix makes one cycle travel exactly one tile: background size `250% → 200%` (`Shimmer.tsx`) and keyframe endpoint `-200% → 0%` (`tailwind.config.js`) — the two are coupled (endpoint = size/(size−100%)), commented in both files. Side effect: the sweep is now one pass per 2s instead of ~2.4, i.e. visibly calmer; tune via the `animation` duration, never the position values. Client-only, **live after refresh, no restart**. Upstream candidate (tracked above). **Not yet live-verified.** **S**
