# Contributing

CLIde is a personal fork, maintained for one person's daily use. Issues are welcome:
bug reports, questions and ideas all help. Pull requests may sit a while or be
reimplemented rather than merged, since the project follows its own direction.

- How work is done here (branches, commits, checks, docs): [AGENTS.md](AGENTS.md)
- How the system is designed: [ARCHITECTURE.md](ARCHITECTURE.md)

Contributions are accepted under the project's licence, AGPL-3.0-or-later.
