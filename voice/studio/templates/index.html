Which file owns whatwhen something sounds wrong
  1. Prepared text wrong? The speech rules. Edit ~/voice/shim/normalizer.py.
  2. Prepared text right, phonemes wrong? eSpeak. Fix by respelling the word in normalizer.py.
  3. Both right, still sounds wrong? The voice model. Try another voice; record it as a limitation.
  4. Pauses too short or long? sentence_silence_seconds and structure_silence_seconds per voice in ~/voice/shim/app.py.

After editing either file: systemctl --user restart voice-shim
